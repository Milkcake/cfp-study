📐 TVM — มูลค่าเงินตามเวลา

FV (Lump Sum)
FV = PV × (1 + i)ⁿ
PV (Lump Sum)
PV = FV / (1 + i)ⁿ
FVA (Ordinary Annuity)
FVA = PMT × [(1+i)ⁿ − 1] / i
PVA (Ordinary Annuity)
PVA = PMT × [1 − 1/(1+i)ⁿ] / i
FVAD / PVAD (Annuity Due)
FVAD = FVA × (1 + i) PVAD = PVA × (1 + i)
Perpetuity
PV = PMT / i
EIR (Effective Interest Rate)
EIR = (1 + i/m)ᵐ − 1
Rule of 72
T = 72 / r (ปีที่เงินเป็น 2 เท่า)
Add-on Rate → True Rate
True Rate ≈ Add-on Rate × 2

TOPIC 1

ความรู้เบื้องต้นเกี่ยวกับการวางแผนการเงิน

กระบวนการวางแผน ECADIR · Wealth Management · SMART Goals

📌 T1-00: ความหมายและความสำคัญของการวางแผนทางการเงิน

ความหมาย

  • กระบวนการประเมินและปรับปรุงสถานะทางการเงิน และการบริหารทรัพยากรเงินทั้งการจัดหาและใช้ไปตามเป้าหมายของบุคคล เพื่อยกระดับคุณภาพชีวิตที่สูงขึ้นและความมั่นคงในชีวิต
  • เป็นกิจกรรมที่เกิดขึ้น ตลอดช่วงชีวิต (life-long activity)
  • วัตถุประสงค์ทางการเงินที่ตั้งไว้ไม่จำเป็นต้องคงที่ มีการเปลี่ยนแปลงได้ทั้งลักษณะและความสำคัญ
  • สะท้อนความสัมพันธ์: "เราอยู่ ณ ที่ใดในปัจจุบัน" กับ "เราต้องการไป ณ ที่ใดในอนาคต" ภายใต้เงื่อนไขข้อจำกัดเฉพาะของแต่ละบุคคล

ประเภทการวางแผน

ประเภทความหมาย
Comprehensive Financial Planningครอบคลุมกิจกรรมทางการเงินทั้งหมด: ลงทุน ประกัน เกษียณ ภาษี ช่วยให้เกิดความมั่นคงทางการเงินในทุกช่วงวงจรชีวิต
Special Needs Planningตอบสนองความต้องการและเป้าหมายเฉพาะของบุคคล เลือกวางแผนเฉพาะด้านที่ต้องการ

สาเหตุที่บุคคลละเลยการวางแผนทางการเงิน

กลุ่มสาเหตุตัวอย่างผลกระทบ
ด้านฐานะคิดว่าตัวเองยังไม่มีเงินมากพอที่จะวางแผนไม่บรรลุเป้าหมายทางการเงิน · เป็นภาระตนเองและผู้อื่น · ประสบปัญหาในบั้นปลายชีวิต · สูญเสียทางการเงิน
ด้านทัศนคติคิดว่าการวางแผนเป็นเรื่องยุ่งยาก · ไม่รู้ว่าควรเริ่มต้นที่ไหน

ปัจจัยที่ทำให้การวางแผนทางการเงินทวีความสำคัญเพิ่มขึ้น

  • ภาวะเศรษฐกิจมีการปรับตัวอย่างรุนแรง
  • การยกเลิกการคุ้มครองเงินฝากประชาชนเต็มจำนวนโดยภาครัฐ
  • ตราสารทางการเงินปัจจุบันมีความซับซ้อนยิ่งขึ้น ยากต่อการเข้าใจ
  • การขยายขอบเขตในการประกอบธุรกิจของสถาบันการเงิน
  • โครงสร้างประชากรที่เปลี่ยนแปลงไป → Aging Society

📋 T1-03: C — Collect รวบรวมข้อมูล

ข้อมูล 6 หมวด

หมวดตัวอย่าง
1. ข้อมูลส่วนตัวอายุ สุขภาพ ครอบครัว อาชีพ
2. ข้อมูลการเงินรายได้ รายจ่าย สินทรัพย์ หนี้สิน
3. เป้าหมายระยะสั้น กลาง ยาว SMART
4. ความเสี่ยงTolerance / Capacity / Required
5. ภาษีฐานภาษี ค่าลดหย่อนที่ใช้อยู่
6. กฎหมาย/มรดกพินัยกรรม ทรัสต์ ผู้รับผลประโยชน์

ความเสี่ยง 3 มิติ (สำคัญมาก)

ประเภทความหมาย

Risk Requiredต้องรับความเสี่ยงเท่าไรเพื่อบรรลุเป้าหมาย

⭐ ต้องรวบรวม "ครบ" ก่อนวิเคราะห์ ไม่ใช่แค่ข้อมูลที่ลูกค้ายื่นให้

🔬 T1-04: A — Analyze วิเคราะห์สถานะ

1. การวิเคราะห์สถานภาพโดยรวม

  • วิเคราะห์: งบดุล / งบกระแสเงินสด / อัตราส่วนทางการเงิน
  • ค่าตอบแทน: ทำประกันชีวิต ประกันสุขภาพ TPD
  • ค่าตอบแทนการวางแผนเกษียณ
  • ทดสอบฝัน + กับแผนปัจจุบัน (เบื้องต้น)

2. แนวทางประเมินข้อมูลลูกค้าที่งดงาม

  • ขอข้อมูลที่ครบ / จัดลำดับเป้าหมาย
  • ช่วยลูกค้า กำหนด + จัดลำดับเป้าหมาย
  • ถ้าเปลี่ยนเล็กน้อย → แก้เฉพาะส่วนได้
  • ถ้ามีการเปลี่ยนแปลงสำคัญ → คุยเรื่องทั้งหมดใหม่ (CF)
  • ถ้าปลี่ยนแปลงระบบขิ้ตัวสำคัญ → พบลูกค้า + กำหนดเงื่อนไขที่เก็บ

อัตราผลตอบแทนตามสมมติฐาน จากการจัดสรรทุนปัจจุบัน

ผลปบ / PVD / กบข.ใช้ตามจริง

⚙️ T1-06: I — Implement & R — Review

I — Implement ทำตามแผน (3 ส่วน)

ส่วนรายละเอียด
1. จัดทำข้อตกลงกับลูกค้าวางแผนแล้ว → ทำข้อตกลงเป็นลายลักษณ์อักษร ✏️ · ให้ลูกค้าดูก่อนเริ่ม · วิธีที่ดีที่สุด → กำหนดค.ผูกพันทางกฎหมาย
2. แผนปฏิบัติการ (Action Plan)วิธีดำเนินการ · วันสิ้นสุดดำเนินงาน · ผู้รับผิดชอบ · ผลลัพธ์ที่ต้องการ
3. กระบวนการรับข้อร้องเรียนฝ่ายรับเรื่อง + คนรับเรื่อง · ฝึกกระบวนการมาตรฐาน · ผู้ควบคุมดูแล + ตรวจสอบข้อร้องทุกวัน · สร้างระบบ feedback loop

องค์ประกอบของข้อตกลง

  • ชื่อ CFP และลูกค้า · ขอบเขตบริการ · บทบาทและความรับผิดชอบ
  • กำหนดเวลาของกิจกรรม · วิธีสนับสนุนการลงทุน
  • ประเภทสินทรัพย์ที่แนะนำ · กรรมวิธีรับมอบสิ่งของ
  • วิธีเก็บรักษา/สำรองข้อมูล · ข้อกำหนดต่ออายุ / ความลับ

R — Review ทบทวน 4 ด้าน

ด้านสาระ
1. ทบทวนแผนการเงินPeriodic + เมื่อมี Trigger Events · ให้ลูกค้าตั้งใจให้ใกล้สุด
ประโยชน์: ลูกค้าเชื่อมั่น + ปรับปรุงให้เหมาะสถานการณ์
2. คงให้บริการต่อเนื่องติดตามสม่ำเสมอ
3. รักษาลูกค้าสร้างความสัมพันธ์ระยะยาว
4. จัดพบพยานต่อสำนวงลูกค้าUpdate ข้อมูลลูกค้าสม่ำเสมอ

⭐ Trigger Events: เปลี่ยนงาน แต่งงาน มีบุตร เกษียณ ได้รับมรดก ป่วยหนัก ได้รับสินทรัพย์ใหม่

#ข้อความหมายหลักรายละเอียด
1Integrity
ความซื่อสัตย์		ไม่หลอกลวง ไม่ฉ้อโกง✅ พูด/เขียนซื่อสัตย์ complete disclosure
✅ ไม่ให้ข้อมูลที่ทำให้เข้าใจผิด
✅ เปิดเผย Conflict of Interest ทุกครั้ง
✅ ไม่รับสิ่งตอบแทนที่ขัดผลประโยชน์ลูกค้า
2Objectivity
ความเที่ยงธรรม		ปราศจากอคติ ให้คำแนะนำโดยอิสระ✅ ให้คำแนะนำปราศจากอคติ ความลำเอียง
✅ ไม่ให้ความสัมพันธ์ส่วนตัวมีผล
✅ คำแนะนำต้องตรงกับประโยชน์ลูกค้า
★ ต้อง Objective กับลูกค้า/นายจ้าง
3Competence
ความรู้ความสามารถ		มีความรู้ทักษะเพียงพอ✅ มีความรู้ ทักษะ ประสบการณ์เพียงพอ
✅ พัฒนาต่อเนื่อง CPD
✅ รู้ขอบเขตตัวเอง ถ้าเกิน → ส่งต่อผู้เชี่ยวชาญ
★ ต้องรู้จริง ไม่ใช่แค่มีใบอนุญาต
4Fairness
ความเป็นธรรม		ปฏิบัติต่อทุกคนอย่างเท่าเทียม✅ ปฏิบัติต่อลูกค้า คู่ค้า ทุกฝ่ายอย่างเป็นธรรม
✅ เปิดเผย Conflict of Interest ทั้งหมด
✅ ทุกลูกค้าได้มาตรฐานเดียวกัน
★ ลูกค้า > ตนเอง > บุคคลที่สาม
5Confidentiality

✅ ใช้ข้อมูลเฉพาะเพื่อประโยชน์ลูกค้า
✅ ดูแลทั้งในและหลังสิ้นสุดความสัมพันธ์
★ ยกเว้น: กฎหมายบังคับ / ลูกค้าอนุญาต
6Professionalism
ความเป็นมืออาชีพ		รักษาภาพลักษณ์วิชาชีพ✅ ประพฤติปฏิบัติตนให้เหมาะสม
✅ ไม่กระทำใดๆ เสื่อมเสียชื่อวิชาชีพ CFP
✅ ปฏิบัติตามกฎระเบียบ กฎหมาย จรรยาบรรณ
⚠️ ห้ามเรียกตัวเอง "CFP" หากไม่มีใบอนุญาต
7Diligence
ขยันหมั่นเพียร		ดูแลลูกค้าด้วยมาตรฐานสูงสุด✅ ระมัดระวัง ขยัน มีความรับผิดชอบ
✅ ทำงานรอบคอบ ครบถ้วน ทันกำหนด
✅ ติดตาม ทบทวน อัปเดตแผนสม่ำเสมอ

🧮 T4-02: ฝึกคำนวณ Cost of Credit (ทุกโจทย์)

โจทย์ 1 — Simple Interest: กู้ 500,000 @ 10%/ปี ผ่อน 1 งวด ดาวน์ 120,000

A: ดอกเบี้ย = 500,000 × 10% = 50,000 บาท
B: เงินที่นำไปลงทุน (กู้สุทธิ หักดาวน์+ดอก) = 120,000 − 50,000 = 70,000 บาท
C: แนะนำเหลือ = 500,000 − 70,000 = 430,000 บาท

โจทย์ 2 — Simple (ส่วนบุคคล): กู้ 100,000 @ 20%/ปี ผ่อนเดือนละ 3,000

A: ดอกเบี้ย = 100,000 × 20%/12 = 1,666.67 บาท/เดือน
B: ตัดเงินต้น = 3,000 − 1,666.67 = 1,333.33 บาท/เดือน
C: เหลือเงินต้น = 100,000 − 1,333.33 = 98,666.67 บาท

โจทย์ 3 — Simple: กู้ 50,000 @ 20%/ปี ค่างวด 1,500/เดือน

A: ดอกเบี้ย (เดือนแรก) = 50,000 × 20%/12 = 833.33 บาท
B: ตัดเงินต้น = 1,500 − 833.33 = 666.67 บาท
C: เหลือเงินต้น = 50,000 − 666.67 = 49,333.33 บาท

โจทย์ 4 — Discount Method: กู้ 100,000 @ 15%/ปี ⭐

A: ดอกเบี้ย = 100,000 × 15% = 15,000 บาท
B: เงินที่ได้รับจริง = 100,000 − 15,000 = 85,000 บาท
C: True rate = 15,000 / 85,000 = 17.65% ต่อปี ★ (True > Stated)

โจทย์ 5 — Discount (บัตรเครดิต): 30,000 @ 3%/เดือน + 15%/ปี คืนใน 29 วัน

A: ดอกเบี้ย = 30,000 × 15%/365 × 29 = 368.22 · ค่าธรรมเนียม = 30,000 × 3% = 900
เงินที่ได้รับจริง = 30,000 บาท
B: True rate = (368.22 + 900) / 30,000 × 365/29 = 53.94% ต่อปี

โจทย์ 6 — Add-on (Flat Rate): ซื้อรถ 800,000 ดาวน์ 20% ผ่อน 5 ปี @ 2.5% ⭐

A: ยอดกู้ = 800,000 × 0.8 = 640,000 บาท
B: ดอกเบี้ยทั้งหมด = 640,000 × 2.5% × 5 ปี = 80,000 บาท
C: ค่างวด = (640,000 + 80,000) / 60 เดือน = 12,000 บาท/เดือน ✅

📐 T6-00B: สูตรสมบูรณ์ FV/PV Lump Sum + Multiple Cash Flows

มูลค่าอนาคต — เงินจำนวนเดียว (FV of Lump Sum)

กรณีสูตร
อัตราดอกเบี้ยเท่ากันทุกงวดFVₙ = PV × (1 + i)ⁿ
อัตราดอกเบี้ยต่างกันแต่ละงวดFVₙ = PV × (1+i₁)(1+i₂)...(1+iₙ)
ทบต้น m ครั้ง/ปีFVₙ = PV × (1 + i/m)^(nm)

ตัวอย่าง: ฝาก 10,000 บาท 4%/ปี ทบต้นทุก 6 เดือน 2 ปี (m=2, n=4) → FV = 10,000 × (1.02)⁴ = 10,824.32 บาท

มูลค่าปัจจุบัน — เงินจำนวนเดียว (PV of Lump Sum)

กรณีสูตร
อัตราดอกเบี้ยเท่ากันทุกงวดPV = FVₙ / (1 + i)ⁿ
อัตราดอกเบี้ยต่างกันแต่ละงวดPV = FVₙ / [(1+i₁)(1+i₂)...(1+iₙ)]
ทบต้น m ครั้ง/ปีPV = FVₙ / (1 + i/m)^(nm)

ตัวอย่าง: ต้องการเงิน 100,000 บาท ใน 3 ปี อัตรา 8% ต่อปี → PV = 100,000 / (1.08)³ = 79,383.22 บาท

กระแสเงินสดหลายจำนวนไม่เท่ากัน (Multiple / Unequal Cash Flows)

คำนวณแต่ละกระแสเงินสดแยกกัน แล้วนำมารวมกัน

หา FV ณ ปีที่ 3 (ดอกเบี้ย 4%)หา PV (ดอกเบี้ย 4%)
ฝาก 10,000 วันนี้: 10,000 × (1.04)³ = 11,248.64รับ 20,000 ปีที่ 1: 20,000 / (1.04)¹ = 19,230.77
ฝาก 20,000 ปีที่ 1: 20,000 × (1.04)² = 21,632.00รับ 30,000 ปีที่ 2: 30,000 / (1.04)² = 27,736.69
ฝาก 30,000 ปีที่ 2: 30,000 × (1.04)¹ = 31,200.00
รวม FV = 64,080.64 บาทรวม PV = 46,967.46 บาท

  • Rule of 72 — ใช้ประมาณเท่านั้น ไม่แม่นยำ 100% (เช่น 6% → 72/6 = 12 ปี)
  • Perpetuity — เมื่อ n → ∞, PV = PMT/i (ง่ายมาก เช่น หุ้นบุริมสิทธิ์)
  • Add-on Rate — ดอกเบี้ยที่แท้จริง ≈ Add-on × 2 (ประมาณ)
  • ทบต้นถี่กว่า → FV สูงกว่า (ทบต้นทุกวัน > ทุกเดือน > ทุกปี)
  • คำนวณทุนเพื่อเกษียณ: PV = ค่าใช้จ่ายต่อปี × PVIFAᵢ,ₙ (ใช้ PVA formula)

📊 T6-01: TVM พื้นฐาน — Compound Interest & เครื่องคิดเลข

หลักการดอกเบี้ยทบต้น

  • ในการลงทุนส่วนใหญ่ → อัตราดอกเบี้ยคิดแบบทบต้น เสมอ
  • Stated/Nominal rate (i) = อัตราที่ระบุในสัญญา ยังไม่ได้พิจารณาความถี่
  • Effective Interest Rate (EIR / iEFF) = อัตราดอกเบี้ยที่แท้จริง
iEFF = (1 + i/m)^m − 1
m = จำนวนครั้งที่คิดดอกเบี้ยต่อปี · Ex: ทบทุก 6 เดือน → m = 2 ครั้ง/ปี

ขั้นตอนวิธีกดหมายเหตุ
1. ตั้งทศนิยม 9 ตำแหน่ง2nd → .(FORMAT) → กด ↑↓ จน DEC → ใส่ 9 → ENTERเช็ค: 1+0.1 = 1.1

4. EFF/NOM2nd → 2(ICONV) → เลือก NOM/EFF → ENTER → C/Y = ความถี่ → CPTหา EFF จาก NOM
5. Storage/Recallพิมพ์เลข → STO → เลือกตำแหน่ง 1–9 · RCL → ดึงเลขที่เก็บเลขที่เก็บใน 1–9

Rule of 72

T = 72 / r (r คือ %, ไม่ใช่ทศนิยม) → ระยะเวลาเป็น ปี/เดือน/ไตรมาส

After-tax Return สูตร

After-tax Return = Nominal Rate × (1 − อัตราภาษี)
